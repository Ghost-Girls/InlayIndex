# Array Inline Index 插件预览效果

## 说明
- 使用 `[index]:` 格式显示数组索引标签
- 对于多维数组，显示完整的多维索引如 `[0][0]:`、`[0][1]:` 等
- 对于结构体数组，每个结构体实例显示一个索引标签

---

## 一维数组示例

### 简单一维数组
```cpp
// 原始代码
int Array1[3] = { 1, 2, 3 };

// 预览效果
int Array1[3] = { [0]:1, [1]:2, [2]:3 };
```

```cpp
// 原始代码
int Array2[5] = { 10, 20, 30, 40, 50 };

// 预览效果
int Array2[5] = { [0]:10, [1]:20, [2]:30, [3]:40, [4]:50 };
```

```cpp
// 原始代码
char Array3[4] = { 'a', 'b', 'c', 'd' };

// 预览效果
char Array3[4] = { [0]:'a', [1]:'b', [2]:'c', [3]:'d' };
```

### 自动推断大小
```cpp
// 原始代码
int Array6[] = { 100, 200, 300, 400, 500 };

// 预览效果
int Array6[] = { [0]:100, [1]:200, [2]:300, [3]:400, [4]:500 };
```

## 枚举类型定义示例

### 基础枚举定义
```cpp
// 原始代码
enum Color { RED, GREEN, BLUE };

// 预览效果（显示枚举值）
enum Color { RED=0, GREEN=1, BLUE=2 };
```

**说明**：在枚举定义中，每个枚举成员后显示其对应的整数值，从 0 开始递增。

### 指定值的枚举定义
```cpp
// 原始代码
enum StatusCode { 
    OK = 200,
    CREATED = 201,
    NOT_FOUND = 404,
    INTERNAL_ERROR = 500
};

// 预览效果
enum StatusCode { 
    OK=200,
    CREATED=201,
    NOT_FOUND=404,
    INTERNAL_ERROR=500
};
```

**说明**：对于显式指定值的枚举成员，显示其指定的值；未指定的成员继续递增。

### 混合指定值的枚举
```cpp
// 原始代码
enum MixedEnum { 
    A,      // 0
    B = 10, // 10
    C,      // 11
    D,      // 12
    E = 20  // 20
};

// 预览效果
enum MixedEnum { 
    A=0,
    B=10,
    C=11,
    D=12,
    E=20
};
```

## 枚举数组示例

### 枚举数组初始化
```cpp
// 原始代码
enum Color colors[] = { RED, GREEN, BLUE, RED, BLUE };

// 预览效果（数组索引 + 枚举值）
enum Color colors[] = { [0]:RED, [1]:GREEN, [2]:BLUE, [3]:RED, [4]:BLUE };
```

### 带枚举值提示的数组
```cpp
// 原始代码（如果同时显示数组索引和枚举值）
enum Color colors[] = { RED, GREEN, BLUE };

// 预览效果（两种方案）

// 方案 1：只显示数组索引
enum Color colors[] = { [0]:RED, [1]:GREEN, [2]:BLUE };

// 方案 2：显示数组索引和枚举值（可能过于冗长）
enum Color colors[] = { [0]:RED(0), [1]:GREEN(1), [2]:BLUE(2) };
```

**推荐**：使用方案 1，只显示数组索引。枚举值提示在定义处显示即可，使用时保持简洁。

## 标签格式说明

### 数组索引标签
1. **一维数组**：`[0]:`、`[1]:`、`[2]:` ...
2. **二维数组**：`[0][0]:`、`[0][1]:`、`[1][0]:` ...
3. **三维数组**：`[0][0][0]:`、`[0][0][1]:`、`[0][1][0]:` ...
4. **四维数组**：`[0][0][0][0]:`、`[0][0][0][1]:` ...
5. **结构体数组**：`[0]:{ ... }`、`[1]:{ ... }` ...
6. **枚举数组**：`[0]:RED`、`[1]:GREEN` ...

### 枚举值标签
7. **枚举定义**：`RED=0`、`GREEN=1`、`BLUE=2` ...
   - 在枚举成员后显示 `=值` 格式
   - 自动计算的枚举值从 0 开始递增
   - 显式指定的值保持不变，后续成员继续递增

### 索引显示模式
8. **简洁索引模式**：外层嵌套只显示当前维度的索引
9. **完整索引模式**：外层嵌套显示完整的多维索引

## 注意事项

- 标签不会引入新的字符，只是在内联位置显示索引
- 标签样式应该使用 Visual Studio 的 Inlay Hint 样式（灰色、斜体）
- 标签应该可以配置显示/隐藏
  - 数组索引标签
  - 枚举值标签
  - 索引显示模式（简洁/完整）
- 对于宏展开的数组，由于预处理阶段已完成，应该正常显示索引
- 枚举值标签只在枚举定义处显示，使用时（如数组初始化）只显示数组索引
