# C/C++ 数组索引/枚举值 Inlay Hint VSIX 插件 需求文档

## 一、项目概述

本项目为 Visual Studio 2022/2026 开发 VSIX 扩展插件，核心目标是为 C/C++ 代码提供**数组索引标签**、**枚举值标签**代码嵌入提示（Inlay Hint），通过 Intra-text Adornments 技术实现对标 CLion 等 IDE 的代码可读性增强能力，提升开发效率。

## 二、核心功能需求

### 1. 前端渲染（VS 编辑器集成）

- **技术框架**：基于 VS 扩展框架 `IntraTextAdornmentTag` 实现代码内联标签渲染
- **渲染机制**：使用 WPF TextBlock 控件创建可视化标签，嵌入到文本行内
- **动态更新**：支持实时动态更新，当用户编辑代码时自动刷新标签显示

#### 1.1 数组索引标签

- **一维数组**：`[0]:`、`[1]:`、`[2]:` ...
- **二维数组**：`[0][0]:`、`[0][1]:`、`[1][0]:` ...
- **三维数组**：`[0][0][0]:`、`[0][0][1]:`、`[0][1][0]:` ...
- **四维数组**：`[0][0][0][0]:`、`[0][0][0][1]:` ...
- **结构体数组**：`[0]:{ ... }`、`[1]:{ ... }` ...（标签位于左大括号之前）
- **枚举数组**：`[0]:RED`、`[1]:GREEN` ...（只显示数组索引，不显示枚举值）

#### 1.2 枚举值标签

- **显示位置**：**仅在枚举定义处显示**，使用时不显示枚举值
- **显示格式**：`RED=0`、`GREEN=1`、`BLUE=2`
- **自动计算**：未显式指定值的枚举成员从 0 开始递增
- **显式指定**：显式指定的值保持不变，后续成员继续递增

**示例**：
```cpp
// 枚举定义处（显示枚举值）
enum Color { RED=0, GREEN=1, BLUE=2 };

// 枚举使用时（只显示数组索引）
enum Color colors[] = { [0]:RED, [1]:GREEN, [2]:BLUE };
```

#### 1.3 结构体字段显示

- **字段名显示**：结构体初始化时显示字段名
- **格式**：`.x:`、`.y:` 等
- **嵌套结构体**：递归显示所有层级的字段名

**示例**：
```cpp
struct Point { int x; int y; };
struct Point points[2] = {
    [0]:{ .x:1, .y:2 },
    [1]:{ .x:3, .y:4 }
};
```

#### 1.4 样式与交互

- **主题自适应**：提示样式自适应 VS 主题（深色/浅色）
- **可定制样式**：支持自定义字体、颜色、边距等
- **无干扰**：不干扰代码编辑、格式化、折叠等原生操作
- **工具提示**：鼠标悬停时显示额外信息

### 2. 后台代码解析

- **解析器**：采用 **ClangSharp (libclang)** 作为 C/C++ 代码解析器
- **解析能力**：
  - 提取数组定义、初始化列表的语法节点
  - 提取枚举定义、枚举常量值
  - 处理多维数组、嵌套结构体
  - 支持 C++11/14/17/20 新特性（如 `std::array`、统一初始化等）
  - 支持 C 语言标准语法
- **位置映射**：从 AST 节点精准映射回源代码位置（字符偏移量）
- **宏处理**：支持处理预处理后的代码（宏展开后的位置映射）

#### 2.1 支持的语言标准

- **C 语言**：C89/C99/C11/C17/C23
- **C++ 语言**：C++11/C++14/C++17/C++20/C++23
- **编译器扩展**：支持常见编译器扩展语法（GCC、Clang、MSVC）

#### 2.2 解析范围

- **全局数组**：文件作用域、命名空间作用域的数组
- **局部数组**：函数内部的数组
- **类成员数组**：类/结构体成员中的数组
- **动态更新**：编辑时实时重新解析受影响区域

### 3. 项目架构与调试方案

- **解决方案结构**：
  1. `InlayIndex`：核心 VSIX 插件工程，编译生成 `.vsix` 安装包
  2. `InlayIndex.Demo`：调试宿主工程，无需安装插件即可调试

- **调试模式**：
  - `InlayIndex.Demo` 直接对接 VS 实验实例（Experimental Instance）
  - 实时输出解析日志、渲染日志到 VS 输出终端
  - 无需手动安装 `.vsix`，一键启动调试，支持断点、单步执行

- **输出要求**：
  - 核心工程输出标准 `.vsix` 插件文件
  - 调试工程不生成安装包，仅作为调试载体

## 三、配置选项

### 3.1 功能开关

- **启用/禁用数组索引标签**
  - 默认：启用
  - 控制是否显示数组索引提示
  
- **启用/禁用枚举值标签**
  - 默认：启用
  - 控制是否在枚举定义处显示枚举值

- **启用/禁用结构体字段名显示**
  - 默认：启用
  - 控制是否显示 `.x:`、`.y:` 等字段名

### 3.2 样式配置

- **颜色主题选择**
  - 橙色主题（默认）：RGB(230, 100, 0)
  - 蓝色主题：RGB(0, 100, 230)
  - 绿色主题：RGB(0, 180, 50)
  - 高对比度主题：RGB(255, 255, 0)

- **字体大小**
  - 范围：9-14pt
  - 默认：11pt

- **字体粗细**
  - 选项：Normal、Medium、SemiBold、Bold
  - 默认：Bold

- **背景透明度**
  - 范围：0-100%
  - 默认：15%（Alpha=40）

### 3.3 显示限制

- **最大显示维度**
  - 范围：1-4 维
  - 默认：4 维（显示所有维度）
  - 用途：避免过高维度数组显示过于复杂

- **最大元素数量**
  - 范围：100-10000
  - 默认：1000
  - 用途：避免超大数组影响性能

### 3.4 语言支持

- **C 语言支持**
  - 默认：启用
  
- **C++ 语言支持**
  - 默认：启用

## 四、技术栈

- **开发工具**：Visual Studio 2022/2026
- **框架**：VSIX Extensibility Framework、MEF (Managed Extensibility Framework)
- **渲染**：`IntraTextAdornmentTag`、WPF
- **解析**：ClangSharp (libclang)
- **语言**：C# 10.0+

## 五、非功能需求

### 5.1 兼容性

- **Visual Studio 版本**：支持 VS 2022 17.0+、VS 2026 全版本
- **操作系统**：Windows 10/11

### 5.2 稳定性

- **异常处理**：解析异常不崩溃 VS 编辑器，优雅降级

- **错误恢复**：解析失败时自动重试或跳过

### 5.3 可维护性

- **代码结构**：解析逻辑与渲染逻辑解耦
- **模块化设计**：清晰的组件边界和接口定义
