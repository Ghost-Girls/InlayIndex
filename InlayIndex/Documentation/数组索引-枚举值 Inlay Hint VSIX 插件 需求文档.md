# C/C++ 数组索引/枚举值 Inlay Hint VSIX 插件 需求文档
## 一、项目概述
本项目为 Visual Studio 2022/2026 开发 VSIX 扩展插件，核心目标是为 C/C++ 代码提供**数组索引标签**、**枚举值标签**代码嵌入提示（Inlay Hint），实现对标 CLion 等 IDE 的代码可读性增强能力，提升开发效率。

## 二、核心功能需求
### 1. 前端渲染（VS 编辑器集成）
- 基于 VS 扩展框架 `IntraTextAdornmentTag` 实现代码内联标签渲染
- 支持**数组索引标签**：在数组元素赋值/访问位置嵌入索引提示（如 `arr[0] = 1`、`arr[1] = 2`）
- 支持**枚举值标签**：在枚举常量使用位置嵌入枚举名称/值提示（如 `Status.Success = 0`、`Type.Error = 1`）
- 提示样式自适应 VS 主题，不干扰代码编辑、格式化、折叠等原生操作
- 支持开关控制：可在 VS 设置中启用/禁用索引/枚举提示

### 2. 后台代码解析
- 采用 **ClangSharp (libclang)** 作为 C/C++ 代码外部解析器
- 解析能力：
  - 提取数组定义、索引访问、元素赋值的语法节点
  - 提取枚举定义、枚举常量值、枚举使用场景
  - 精准匹配代码位置，为前端渲染提供坐标+文本数据
- 兼容标准 C/C++ 语法，支持常见编译器扩展语法

### 3. 项目架构与调试方案
- 解决方案双工程结构：
  1. `InlayIndex`：核心 VSIX 插件工程，编译生成 `.vsix` 安装包
  2. `InlayIndex.Demo`：调试宿主工程，无需安装插件即可调试
- 调试模式：
  - `InlayIndex.Demo` 直接对接 VS 实验实例（Experimental Instance）
  - 实时输出解析日志、渲染日志到 VS 输出终端
  - 无需手动安装 `.vsix`，一键启动调试，支持断点、单步执行
- 输出要求：
  - 核心工程输出标准 `.vsix` 插件文件
  - 调试工程不生成安装包，仅作为调试载体

## 三、技术栈
- 开发工具：Visual Studio 2022/2026
- 框架：VSIX Extensibility Framework
- 渲染：`IntraTextAdornmentTag`、WPF
- 解析：ClangSharp (libclang)
- 语言：C#

## 四、非功能需求
- 性能：代码解析无明显卡顿，提示渲染低延迟
- 兼容性：支持 VS 2022 17.0+、VS 2026 全版本
- 稳定性：解析异常不崩溃 VS 编辑器
- 可维护性：解析逻辑与渲染逻辑解耦
